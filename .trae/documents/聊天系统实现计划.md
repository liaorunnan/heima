## 数据库设计

### 1. 用户表 (`users`)
- `id`: SERIAL PRIMARY KEY - 用户ID
- `username`: VARCHAR(50) UNIQUE NOT NULL - 用户名
- `password_hash`: VARCHAR(255) NOT NULL - 密码哈希
- `role`: VARCHAR(20) NOT NULL - 角色(customer/merchant)
- `created_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP - 创建时间

### 2. 商品表 (`products`)
- `id`: SERIAL PRIMARY KEY - 商品ID
- `name`: VARCHAR(100) NOT NULL - 商品名称
- `description`: TEXT NOT NULL - 商品描述
- `price`: DECIMAL(10,2) NOT NULL - 商品价格
- `merchant_id`: INTEGER REFERENCES users(id) - 商家ID
- `created_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP - 创建时间

### 3. 聊天室表 (`chat_rooms`)
- `id`: SERIAL PRIMARY KEY - 聊天室ID
- `customer_id`: INTEGER REFERENCES users(id) - 客户ID
- `merchant_id`: INTEGER REFERENCES users(id) - 商家ID
- `created_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP - 创建时间

### 4. 聊天记录表 (`chat_messages`)
- `id`: SERIAL PRIMARY KEY - 消息ID
- `chat_room_id`: INTEGER REFERENCES chat_rooms(id) - 聊天室ID
- `sender_id`: INTEGER REFERENCES users(id) - 发送者ID
- `content`: TEXT NOT NULL - 消息内容
- `message_type`: VARCHAR(20) NOT NULL - 消息类型(text/product)
- `product_id`: INTEGER REFERENCES products(id) NULL - 商品ID(消息类型为product时使用)
- `created_at`: TIMESTAMP DEFAULT CURRENT_TIMESTAMP - 发送时间

## 后端实现

### 技术栈
- **框架**: FastAPI
- **数据库**: PostgreSQL
- **认证**: JWT
- **密码加密**: bcrypt

### 核心API接口
1. **认证接口**
   - POST /api/auth/register - 注册
   - POST /api/auth/login - 登录

2. **聊天接口**
   - GET /api/chat/rooms - 获取用户的聊天室列表
   - GET /api/chat/rooms/{room_id}/messages - 获取聊天室消息
   - POST /api/chat/rooms/{room_id}/messages - 发送消息

3. **商品接口**
   - GET /api/products - 获取商品列表
   - GET /api/products/{product_id} - 获取商品详情
   - POST /api/products - 创建商品(商家)
   - PUT /api/products/{product_id} - 更新商品(商家)
   - DELETE /api/products/{product_id} - 删除商品(商家)

## 功能实现细节

### 1. 商品卡片功能
- 商家在聊天窗口中可选择商品发送为卡片
- 客户收到卡片后可点击查看商品详情
- 商品卡片包含商品名称、价格和简短描述

### 2. 聊天记录管理
- 所有聊天记录保存到数据库
- 支持查看历史聊天记录
- 消息按时间顺序显示

### 3. 用户认证
- 使用JWT进行无状态认证
- 密码使用bcrypt加密存储
- 前端LocalStorage存储认证令牌

### 4. 数据库初始化
- 自动创建数据表结构
- 添加必要的索引以提高查询性能
