# 旧推荐系统优化方案：融合新系统核心算法与提示词

我们将把 `src` 目录（新系统）中的工程化优势、鲁棒性算法以及更严谨的提示词策略注入到 `tuijianxiton`（旧系统）中。

## 核心优化点

### 1. 提示词策略升级 (Prompt Engineering)
- **操作**: 将 `tuijianxiton/prompt.py` 替换为 `src/prompt/prompts_tag.py` 中的内容。
- **理由**: 新版提示词引入了 **8项硬性约束**（如反向检查机制、用户视角原则、Key-Value 分离原则），能有效抑制大模型幻觉，确保标签提取的准确性和结构的一致性。

### 2. 标签提取器鲁棒性增强 (LLM Tagger)
- **操作**: 在 `tuijianxiton/llm_tagger.py` 中：
    - 引入 `parse_llm_json` 函数，处理大模型输出中可能夹带的 Markdown 标记。
    - 保留旧系统的 `response_format={"type": "json_object"}` 强制约束，实现双重保障。
- **理由**: 提高系统对不同 LLM 模型输出格式的兼容性。

### 3. 画像系统算法重构 (User Persona Algorithm)
- **操作**: 对 `tuijianxiton/user_persona.py` 进行深度重构，引入 `src` 的核心算法：
    - **冲突抑制逻辑 (`_suppress_conflicting_values`)**: 当用户更新偏好时（如选了黑色），自动对该维度下其他颜色进行降权。
    - **过期与噪音控制**: 引入短时间内重复输入的噪音抑制（5分钟间隔检查）以及过期数据自动清理。
    - **时间体系升级**: 统一使用 `YYYY-MM-DD HH:MM:SS` 格式，增强画像的可读性和工程兼容性。
    - **摘要生成增强**: 保留旧系统的自然语言摘要功能，并根据新的标签结构进行适配。

### 4. 数据一致性优化
- **操作**: 在更新画像时，强制执行 `tag_code` 与 `value` 的分离，修复 Key-Value 混合问题（例如将 "性别-男" 自动修正为 code="性别", value="男"）。

## 实施步骤

1.  **同步提示词**: 覆盖 `tuijianxiton/prompt.py`。
2.  **重写画像类**: 在 `tuijianxiton/user_persona.py` 中合并两个系统的优点。
3.  **优化提取逻辑**: 修改 `tuijianxiton/llm_tagger.py`。
4.  **编写技术文档**: 在 `tuijianxiton/doc/优化说明文档.md` 中记录所有变更理由。
