# 项目README文件创建计划

## 项目概述
- 这是一个基于FastAPI的聊天系统，包含前后端代码
- 后端使用PostgreSQL数据库存储数据
- 前端分为customer和merchant两个界面

## 数据库初始化说明
- 数据库表会在应用启动时自动创建（通过`main.py`中的`Base.metadata.create_all(bind=engine)`）
- 但需要先确保PostgreSQL数据库服务运行，并创建相应的数据库和用户
