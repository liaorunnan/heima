# 用户画像与推荐系统优化说明文档

本文档详细说明了对旧推荐系统（`tuijianxiton`）进行的各项优化及其背后的技术理由。本次优化融合了新系统（`src`）的生产级工程经验与旧系统的算法特性。

## 1. 提示词工程 (Prompt Engineering) 升级

### 优化内容
- 替换 `tuijianxiton/prompt.py` 为最新版 `AI_TAG_PROMPT`。
- 引入了 8 项核心约束规则：
  1. **反向检查机制**: 强制要求标签必须有原文证据支撑。
  2. **用户视角原则**: 严禁提取非用户本人的需求。
  3. **主体检测**: 准确区分用户、客服及第三方引用。
  4. **指令独立化**: 分离即时操作指令。
  5. **颗粒度控制**: 区分心理特征与硬性指标。
  6. **使用对象提取**: 识别为他人购买的场景。
  7. **Key-Value 分离**: 确保 `tag_code` 与 `value` 的结构化清晰。
  8. **客服推荐排除**: 避免将客服单方面推荐误认为用户需求。

### 优化理由
- **抑制幻觉**: 通过反向检查减少大模型的“脑补”行为。
- **结构化准确性**: Key-Value 分离解决了旧系统中常见的标签混乱问题。

## 2. 标签提取器鲁棒性增强

### 优化内容
- 增加了 `parse_llm_json` 函数，专门处理大模型输出中可能夹带的 ```json ... ``` 标记。
- 在 `extract_user_tags` 中增加了异常处理逻辑。

### 优化理由
- **格式兼容性**: 不同的大模型在输出 JSON 时可能会夹带 Markdown 标记，增加解析逻辑可大幅提升系统的健壮性，减少程序崩溃。

## 3. 画像管理算法升级 (核心算法)

### 优化内容
- **冲突抑制逻辑 (`_suppress_conflicting_values`)**: 
  - 当用户更新同一维度的值时（如颜色从“红色”改为“黑色”），系统会自动对“红色”进行降权。
- **噪音控制机制**: 
  - 在 `update_persona` 中增加了 5 分钟间隔检查。短时间内重复提及同一需求不会导致分值线性叠加，有效防止了数据“刷分”。
- **精细化分值对齐**:
  - 采用了更科学的 `TIER_MAP`（S/A/B 级置信度）和 `TYPE_WEIGHT`（Requirement/Concern/Inquiry/Attribute 权重）。
- **自动化过期与清理**:
  - 引入 `_resolve_conflicts_and_clean_expired` 方法，自动移除低分噪音数据和已过期的品类意图。
- **时间体系统一**:
  - 放弃了纯 Unix 时间戳，改用 `YYYY-MM-DD HH:MM:SS` 格式，增强了数据库的可读性和后期维护的便利性。

### 优化理由
- **画像准确性**: 冲突抑制解决了画像自相矛盾的问题。
- **生产级鲁棒性**: 噪音控制和清理逻辑确保了画像系统在长期运行中不会被无效或过期数据撑爆。

## 4. 画像摘要生成增强

### 优化内容
- 保留并重构了 `_generate_summary` 方法。
- 摘要现在能够识别并描述“衍生特质”（如极致性价比追求者）和“风险偏好”。

### 优化理由
- **可解释性**: 将结构化的 JSON 画像转化为自然语言，帮助运营人员和客服更直观地理解用户画像。

---

**总结**: 经过此次优化，系统在保持原有灵活性的基础上，大幅提升了在生产环境中的稳定性和画像刻画的精准度。
